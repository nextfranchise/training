Card 4.1 Ecosystem Integrity

The Deliberate Zero

A franchise network thrives when everyone gains. The Value Map explicitly documents where the franchisor deliberately captures nothing.

Stakeholder Value Created by System Franchisor Value Capture
Franchisee Turnkey business model, training, brand power Franchise fee, monthly system fee

Key Takeaways for Module 8

  • 1. '5% Royalty' is Not an Answer: Always calculate the royalty at Break-even. If fees consume 100% of the franchisee's profit at break-even, the system fails.
  • 2. Protect Slow Starters: Teamworks waives the first 100 therapy sessions so new centers don't pay royalties while establishing a clinical caseload.
  • 3. Term Tracing: Every term in the Franchise Agreement must trace directly to a card. An unlinked term was copied blindly from another agreement.
